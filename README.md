# 3D Haunted House 
 
## About the Game 
3D Haunted House is a game developed using Unity and C#. 
 
Players explore a haunted house and experience a mysterious 
and spooky environment. 
 
## Game Features 
- 3D haunted house environment 
- Interactive main menu 
- Player movement and exploration 
- Immersive horror atmosphere 
 
## Technologies Used 
- Unity 
- C# 
- Visual Studio Code 
- Git and GitHub 
 
## How to Play 
1. Open the game using the Unity Play link below. 
2. Click the Start button. 
3. Explore the haunted house. 
 
## Play the Game 
Play on Unity Play: https://play.unity.com/api/v1/games/game/e55e8181-2ba9-40a4-9b8a-44e0c7aca6f3/build/latest/frame
